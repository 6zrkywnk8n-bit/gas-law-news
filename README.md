# 保安法令ニュース ダッシュボード

高圧ガス保安法・液化石油ガス法・火薬類取締法に関するニュースを、官公庁・業界団体・
一般ニュースから自動で集め、1 枚の HTML ダッシュボードにまとめる業務用ツールです。

外部ライブラリは一切使いません（Python 標準ライブラリのみ）。`pip install` は不要で、
プロキシで pip が塞がれている社内 PC でもそのまま動きます。

## 使い方

1. `update.bat` をダブルクリック → 収集してブラウザでダッシュボードが開きます。
2. 2 回目以降も同じ操作。前回実行以降に増えた記事には **NEW** の印が付きます。
3. 収集せずに見るだけなら `open.bat`。

コマンドラインから使う場合:

```bash
python main.py                          # 収集して dist/index.html を開く
python main.py --no-open                # ブラウザを開かない（定時実行向け）
python main.py --no-fetch               # 収集せず、蓄積済みデータから作り直す
python main.py --only khk_top,gn_kayaku # 特定の情報源だけ収集
```

## ダッシュボードでできること

| 機能 | 説明 |
|---|---|
| 法令フィルタ | 高圧ガス保安法／液石法／火取法のタグで絞り込み（複数選択可） |
| 内容フィルタ | 法令改正・意見公募・事故・行政処分・通達解釈・講習試験で絞り込み |
| 重要度順 | 「改正」「意見公募」「事故」など実務インパクトの大きい語を含む記事を上位に |
| 新着 / ★ / 未読 | 読んだものを畳み、気になるものにブックマーク（このブラウザに保存） |
| Markdown コピー | 表示中の一覧を回覧用に整形してクリップボードへ |
| CSV 保存 | 表示中の一覧を Excel で開ける CSV（BOM 付き UTF-8）で書き出し |

## 外出先からいつでも最新を見る（GitHub で自動更新）

パソコンの電源に関係なく、**毎朝 8 時に自動でニュースを集め直し、スマホから
URL を開くだけで最新が見られる**ようにできます。無料です。

準備は最初の一度だけ。以下の 5 ステップです。

### ステップ 1: GitHub のアカウントを作る（5 分）

https://github.com/signup にアクセスし、メールアドレスとパスワードを決めて登録します。
無料プランのままで大丈夫です。

### ステップ 2: 置き場所（リポジトリ）を作る

1. ログインした状態で https://github.com/new を開く
2. **Repository name** に `gas-law-news` と入力
3. **Public**（公開）を選ぶ ※ Private だと無料プランでこの仕組みが使えません
4. 下の「Add a README file」などのチェックは**すべて外したまま**にする
5. 緑の **Create repository** ボタンを押す
6. 次に出るページの URL（`https://github.com/あなたの名前/gas-law-news`）をコピーしておく

### ステップ 3: このフォルダを送る

`github-setup.bat` をダブルクリックし、さきほどの URL を貼り付けて Enter。
初回はブラウザで GitHub のログイン画面が出るので、許可してください。

### ステップ 4: ページの公開を有効にする

1. GitHub のリポジトリのページで、上の **Settings**（歯車）タブを開く
2. 左メニューの **Pages** を選ぶ
3. **Source** の欄を **GitHub Actions** に変更する

### ステップ 5: 最初の実行を待つ

上の **Actions** タブを開くと処理が動いています。3 分ほどで緑のチェックが付きます。
終わったら Settings → Pages に戻ると、公開 URL が表示されます。

```
https://あなたの名前.github.io/gas-law-news/
```

**この URL をスマホでブックマークすれば完了です。** 以降は毎朝 8 時に中身が入れ替わります。

### すぐ更新したいとき

ページの上にある「GitHub で今すぐ更新」を押す → 出てきた画面の
**Run workflow** ボタンを押すと、その場で集め直しが始まります（3 分ほど）。
GitHub にログインしていれば、スマホからでも押せます。

### 知っておくこと

- **Public（公開）なので、URL を知っている人は誰でも見られます。** 中身は公開されている
  ニュースの見出しとリンクだけなので実害はありませんが、社内限定の情報を足したくなったら
  この方式は使わないでください。
- 集めた履歴は `data/news.db` に貯まり、毎回 GitHub に保存されます。「NEW」の印は
  この履歴を基準に付きます。
- 経産省などが自動アクセスを弾く場合があります。そのときはページ下部の
  「情報源の取得状況」に赤字で出ます。他の情報源は通常どおり集まります。

## スマホで見る（その他の方法）

上の GitHub 方式のほかに、次の 2 つもあります。

### 1. 同じ Wi-Fi から見る（`serve.bat`）

`serve.bat` をダブルクリックすると、収集し直したうえで LAN に公開し、
黒い画面に `http://192.168.x.x:8765/` のような URL が表示されます。
これをスマホのブラウザで開いてください。

- **スマホから更新できます**。ページ上部の「最新に更新」ボタンを押すと PC 側で収集が
  走り（20秒〜1分ほど）、終わると自動で読み込み直して新着に NEW が付きます。
  このボタンは `serve.bat` 経由で開いたときだけ表示されます。
- PC の電源が入っていて、スマホと同じ Wi-Fi につながっている必要があります。
- 初回は Windows ファイアウォールの確認が出ます。「プライベート ネットワーク」を許可してください。
- 止めるときは Ctrl+C、またはそのウィンドウを閉じます。
- ポートを変えたいときは `python serve.py --port 9000`。
- 起動時の収集を省きたいときは `python serve.py --no-update`。

iPhone なら Safari の共有ボタン →「ホーム画面に追加」でアプリのように開けます。

### 2. その時点の内容を共有する（Artifact）

`dist/artifact.html` を Claude の Artifact として公開すると、URL ひとつでどこからでも
（携帯回線でも）開けます。既定は非公開で、必要なら同僚に共有もできます。

- **その時点のスナップショット**です。`update.bat` で収集しても Artifact は自動更新
  されません。最新にしたいときは Claude に「保安法令ニュースのArtifactを更新して」と
  頼んでください（同じ URL のまま差し替わります）。
- Artifact ビューアはページからのファイル保存を許可しないため、CSV ボタンは自動的に
  非表示になります。「一覧をコピー」（Markdown）は使えます。
- 収集を実行する相手（PC）がいないので、「最新に更新」ボタンも出ません。

### 画面の作り

横幅 700px 以下では自動的にスマホ表示に切り替わります。

- 絞り込みパネルは畳まれ、「絞り込み」ボタンで開閉します（適用中の条件数が出ます）
- ★・既読ボタンはタップしやすい大きさに変わります
- 入力欄は 16px に拡大されます（iOS Safari が入力時に勝手に拡大するのを防ぐため）
- 端末のダークモードに追従します

## 収集している情報源

| 区分 | 情報源 |
|---|---|
| 官公庁 | 経済産業省 ニュースリリース、総務省消防庁 報道発表等、産業保安・法令改正のニュース検索 |
| 業界団体 | 高圧ガス保安協会 (KHK) の新着情報とお知らせ一覧、日本LPガス協会 |
| 事故・災害 | 高圧ガス事故、LPガス事故のニュース検索 |
| 一般ニュース | 高圧ガス保安法／液化石油ガス法・LPガス保安／火薬類取締法・煙火保安 のニュース検索 |

各情報源の取得件数と成否は、ダッシュボード下部の「情報源の取得状況」で毎回確認できます。

### 経済産業省サイトについての注意

`www.meti.go.jp` は AWS WAF による Bot 対策が入っており、短時間に連続アクセスすると
JavaScript チャレンジを返して本文を取得できなくなります。ツール側はこれを検知して
「アクセス制限（Bot対策）のため本文を取得できませんでした」と状態表示します。
1 日 1 回程度の通常運用なら取得できますが、弾かれた場合は時間をおいて再実行してください。
なお経産省の発表は「ニュース検索: 産業保安・法令改正」からも拾えるようにしてあります。

## 設定の変更

### 情報源を足す・止める — `config/sources.json`

```json
{
  "id": "任意のID",
  "name": "画面に出す名前",
  "category": "官公庁 | 業界団体 | 事故・災害 | 一般ニュース",
  "parser": "rss",
  "url": "https://example.jp/rss.xml",
  "filter": true,
  "default_laws": ["高圧ガス保安法"],
  "enabled": true
}
```

- `parser`: `rss`（RSS/Atom）、`meti_press`、`fdma_press`、`khk_news`、`generic_list`（汎用）
- `filter`: `true` にすると、法令キーワードに当たらない記事を捨てます。省庁の全プレスなど
  対象の広い情報源では `true`、専門サイトでは `false` が向きます。
- `default_laws`: キーワードで法令が特定できなかったときに当てる法令。所管が自明な
  団体サイト向けです。
- 一時的に止めたいだけなら `"enabled": false`。

**ニュース検索を増やしたいとき**は Google ニュースの RSS が使えます。
`https://news.google.com/rss/search?q=<URLエンコードした検索式>&hl=ja&gl=JP&ceid=JP:ja`
検索式は `("高圧ガス保安法" OR (容器再検査 AND 改正))` のように AND / OR / 引用符が使えます。

### 法令の判定語を調整する — `config/keywords.json`

- `strong`: 1 語で法令を特定できる語（+10 点）
- `normal`: 補助的な語（+4 点）
- `exclude`: これを含む記事はノイズとして落とす語

自社の設備名や取扱ガス種（例: `アンモニア`、`塩素`、`CE`）を `normal` に足すと、
自分の業務に近い記事が上位に来ます。

内容の区分と重み（法令改正 +18、意見公募 +16、事故 +14 …）は `src/classify.py` の
`SIGNAL_WEIGHTS` にあります。

## 毎朝自動で更新する（Windows タスクスケジューラ）

1. 「タスク スケジューラ」→「基本タスクの作成」
2. トリガー: 毎日 8:00 など
3. 操作: プログラムの開始
   - プログラム: `python`
   - 引数: `main.py --no-open`
   - 開始（作業フォルダー）: `C:\アプリ開発\gas-law-news`
4. 出社したら `open.bat` で開くだけ。前回からの差分に NEW が付いています。

## 更新 API について

`serve.bat` で起動しているときだけ、次の 2 つが有効になります。

| メソッド | パス | 動作 |
|---|---|---|
| GET | `/api/ping` | 収集サーバーかどうかをページ側が確かめる。ボタンの表示判定に使う |
| POST | `/api/update` | `main.py --no-open` を決め打ちで実行する |

どちらもリクエストの中身を一切使いません（引数やパスを実行内容に反映しないため、
外から任意のコマンドを走らせることはできません）。実行するのは公開ニュースの収集だけです。
とはいえ同じ LAN にいる人なら誰でも収集を起動できるので、社外の共有 Wi-Fi など
信頼できないネットワークでは `serve.bat` を立ち上げっぱなしにしないでください。
収集は同時に 1 本だけ走るようロックしてあります。

## 仕組みのメモ

- **日付**: 「令和８年８月27日」のような和暦・全角表記、`2026/08/10`、RSS の pubDate に対応。
  取れないときは URL の `/2026/08/` から補完します。
- **重複除去**: 同じ発表が複数媒体・複数クエリから来るため、記号と空白を落とした
  題名の前方 32 文字＋日付で名寄せします（`src/util.py` の `dedup_key`）。
- **新着判定**: 記事の日付ではなく「このツールが最初に見つけた日時」が前回実行より
  後かどうかで決めます。古い記事が後から出てきた場合も見落としません。
- **蓄積型**: 各サイトは直近ぶんしか一覧に出しませんが、DB に貯め続けるので、
  定期実行するほど過去の履歴が厚くなります。
